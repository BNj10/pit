## Notes for editors

- `[Screenshot: …]` lines mark where a screenshot should go. Replace them with images when screenshots are taken.
- During the current development stage, only sign-in, account setup, and password resets are saved. Other changes in the portals reset when the page reloads, so some steps here describe the intended behavior rather than saved results.
