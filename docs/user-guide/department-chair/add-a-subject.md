# Add a subject to a curriculum

## Overview
Add a subject to a draft curriculum, place it in a year level and semester, and set its units, prerequisites, and corequisites.

## Before you begin
- The curriculum is a **Draft**.
- For prerequisites: the required subjects are already in an earlier term of this curriculum.

## Steps
1. Select **Curricula and Subjects**, then select the curriculum's name to open it.
2. Select **Add subject**.
3. Fill in:
   - **Subject code**, e.g. *CC 101*
   - **Subject title**, e.g. *Introduction to Computing*
   - **Year level** and **Semester**
   - **Lecture units** and **Laboratory units** (whole numbers; both can't be 0). **Total units** is calculated for you.
   - **Prerequisites**: subjects from earlier terms that must be completed first
   - **Corequisites**: subjects in the same term that must be taken together
4. Select **Add subject**.
   → You'll see "[code] was added to [term]."

## Troubleshooting
| Problem | What to do |
|---|---|
| "Enter a subject code." / "Enter a subject title." | Fill in the required field. |
| "[code] is already in this curriculum." | Use a different code, or edit the existing subject. |
| "Lecture and laboratory units cannot both be 0." | Give the subject at least one lecture or laboratory unit. |
| "Enter a whole number from 0 to …" | Units must be whole numbers within the range shown. |
| "Choose a year level and semester." | Select both. |
| "No subjects in earlier terms…" under Prerequisites | Add the prerequisite subjects to an earlier term first. |
| "… must be in a term before …" | A prerequisite must come from an earlier term. Remove it or choose a later term for this subject. |
| "… must be in [term] to be taken together." | Corequisites must be in the same term. |
| Active or Archived curricula are read-only | Deactivate the curriculum, or restore it to draft, to edit its subjects. |
