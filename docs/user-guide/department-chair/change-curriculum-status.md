# Activate, deactivate, or restore a curriculum

## Overview
Move a curriculum between statuses. **Active** curricula are in use and read-only. **Draft** curricula can be edited. **Archived** curricula are kept for reference.

## Before you begin
- You're logged in as a Department Chair.

## Steps
1. Select **Curricula and Subjects** in the sidebar.
2. Find the curriculum.
3. Select the action on its row:

   | Current status | Action | Result |
   |---|---|---|
   | Draft | **Activate** | Becomes Active: "[name] is now active." |
   | Active | **Deactivate** | Moves back to Draft so you can edit it: "[name] was moved to draft." |
   | Archived | **Restore to draft** | Becomes Draft again: "[name] was restored to draft." |

## Troubleshooting
| Problem | What to do |
|---|---|
| "[name] can't be activated: [codes] … already used by [curriculum]. Give revised subjects new codes." | Another active curriculum uses the same subject codes. Give the revised subjects new codes, or deactivate the other curriculum. |
| You want to archive an active curriculum | Deactivate it first, then [archive it](archive-a-curriculum.md). |
