# Delete a subject

## Overview
Remove a subject from a draft curriculum. This can't be undone.

## Before you begin
- The curriculum is a **Draft**.
- No other subject lists this one as a prerequisite or corequisite.

## Steps
1. Select **Curricula and Subjects**, then open the curriculum.
2. Select the subject's delete button.
   → The **Delete this subject?** dialog opens.
3. Type the subject code in **Enter subject code**.
4. Confirm the deletion.
   → You'll see "[code] was deleted from [curriculum]."

[Screenshot: The Delete this subject dialog]

## Troubleshooting
| Problem | What to do |
|---|---|
| "This subject is required by other subjects" | Edit those subjects to remove this one from their prerequisites or corequisites, then try again. |
| The delete button stays unavailable | Type the subject code exactly as shown. |
