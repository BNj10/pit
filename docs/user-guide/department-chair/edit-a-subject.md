# Edit a subject

## Overview
Change a subject's code, title, units, term, prerequisites, or corequisites in a draft curriculum.

## Before you begin
- The curriculum is a **Draft**.

## Steps
1. Select **Curricula and Subjects**, then open the curriculum.
2. Find the subject. Use **Search subject code or title** if the list is long.
3. Select the subject's edit button.
4. Make your changes. Choosing a different **Year level** or **Semester** moves the subject.
5. Select **Save changes**.
   → You'll see "[code] was updated." If you moved it, the message also names the new term.

Adding a corequisite links both subjects, so each lists the other.

## Troubleshooting
| Problem | What to do |
|---|---|
| "[subject] ([term]) lists this subject as a prerequisite. Choose a term before …" | Another subject needs this one first, so it can't move to that term or later. Choose an earlier term, or update the other subject first. |
| "A selected prerequisite is no longer in this curriculum." | Review the selection and remove the missing subject. |
| Other validation messages | See [Add a subject to a curriculum](add-a-subject.md). |
