# Approve or return a student's enrollment

## Overview
Review the subjects a student submitted, then approve the enrollment or return it with a message explaining what to change.

## Before you begin
- The student has submitted their enrollment (status **Pending review**).

## Steps
1. Select **Enrollment Management** in the sidebar.
   → The **Department roster** lists students for the term.
2. Find the student. Use **Search student name or ID** and the **Status** and **Year** filters.
3. Select **Preview** on the student's row.
   → The dialog shows their **Enrollment selection**: subjects, sections, schedules, and total units.
4. Choose one:
   - **To approve:** select **Approve enrollment**, then confirm.
     → You'll see "[student]'s enrollment approved." The status becomes **Approved**.
   - **To return:** select **Return to student**, write a **Message to the student** (e.g. a schedule conflict or a missing subject), then send it.
     → The status becomes **Returned**, and the student sees your message on their dashboard.

Next step after approval: [Mark a student as enrolled](mark-a-student-as-enrolled.md).

## Troubleshooting
| Problem | What to do |
|---|---|
| "Enter a message so the student knows what to change." | A message is required when returning an enrollment. |
| You want to see why an enrollment was returned | Select **View return** on the student's row. |
| The student isn't listed | Clear the search and set the filters back to all statuses and year levels. Students who haven't submitted show as not submitted. |
