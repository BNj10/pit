# Edit a curriculum's details

## Overview
Change a draft curriculum's name, years, or description. Only **Draft** curricula can be edited.

## Before you begin
- The curriculum is a **Draft**. If it's Active, [deactivate it](change-curriculum-status.md) first.

## Steps
1. Select **Curricula and Subjects** in the sidebar.
2. Find the curriculum. Use the status tabs (**All curricula**, **Active**, **Draft**, **Archived**) or **Search curriculum name or code**.
3. Select **Edit** on its row.
4. Change the details you need.
5. Select **Save changes**.
   → You'll see "[name] was updated."

To change its subjects, open the curriculum by selecting its name (see [Edit a subject](edit-a-subject.md)).

## Troubleshooting
| Problem | What to do |
|---|---|
| There's no **Edit** button | The curriculum is Active or Archived. Deactivate it or restore it to draft first. |
| A validation message appears | See the troubleshooting table in [Add a curriculum](add-a-curriculum.md). |
