# Add or edit a section

## Overview
Schedule a section of an offered subject: its name, capacity, faculty member, class type, meeting days and times, and room. PIT Enroll checks for schedule conflicts as you type.

## Before you begin
- The subject is offered in the semester ([Add subjects to offer in a semester](add-subjects-to-offer.md)).

## Steps
1. Select **Sections** and choose the academic year and year level.
2. Expand the semester and the subject.
3. Select **Add section** (or **Add another section**). To change an existing one, select the edit button on its row.
4. Fill in:
   - **Section**, e.g. *BSCS 3-A*
   - **Capacity**, e.g. *40*
   - **Faculty member**, or leave **Unassigned**
   - **Class type**: lecture or laboratory
   - **Schedule**: the meeting days, **Start** time, and end time
   - **Room**, e.g. *ENG 204*, or *TBA* if no room is set yet
5. Check the message at the bottom of the dialog. You want **No schedule conflicts**.
6. Select **Add section** or **Save changes**.
   → You'll see "[code] [section] [type] added." (or "updated.")

To remove an entry, select the delete button on its row, then **Delete entry**.

## Troubleshooting
| Problem | What to do |
|---|---|
| "Enter a section." / "Enter a room." | Fill in the required field. |
| "Enter a capacity of at least 1." | Enter a capacity of 1 or more. |
| "Select at least one meeting day." | Choose the days the section meets. |
| "Enter a start and end time." / "The end time must be after the start time." | Check both times. |
| "[section] already meets for …" | That section block already has a class at this time. Change the time. |
| "[room] is already used by [section] for …" | Choose another room or time. *TBA* never conflicts. |
| "[faculty] already teaches [section] …" | Choose another faculty member or time. |
| "Weekly hours exceed the units" | The weekly meeting hours are more than the subject's units allow (1 unit = 1 hr/week). Shorten the schedule. |
| "Weekly hours below the units" | Add meeting time until it matches the units. |
| "[code] has no lecture/laboratory units in the curriculum." | Choose the other class type. |
