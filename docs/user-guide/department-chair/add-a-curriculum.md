# Add a curriculum

## Overview
Create a new curriculum for your assigned degree program. It starts as a **Draft**, so you can add its subjects before activating it.

## Before you begin
- You're logged in as a Department Chair.
- Know the curriculum's name, curriculum year, and the year it takes effect.

## Steps
1. Select **Curricula and Subjects** in the sidebar.
2. Select **Add curriculum**.
3. Fill in:
   - **Curriculum name**, e.g. *BS Computer Science Curriculum 2026*
   - **Curriculum year**, e.g. *2026*
   - **Year implemented**: the curriculum year or a later year
   - **Description (optional)**
4. Select **Create curriculum**.
   → You'll see "[name] was created as a draft." and the new curriculum opens so you can [add its subjects](add-a-subject.md).

## Troubleshooting
| Problem | What to do |
|---|---|
| "Enter a curriculum name." / "Enter the curriculum year." / "Enter the year implemented." | Fill in the required field. |
| "Enter a four-digit year between …" | Use a four-digit year within the range shown. |
| "Another curriculum in this program already uses this name." | Choose a different name. |
| "A [year] curriculum already exists for this program." | Each program has one curriculum per year. Edit the existing one instead. |
| "Use the curriculum year or a later year." | The year implemented can't be earlier than the curriculum year. |
| "Use … characters or fewer." | Shorten the name or description. |
