# Delete a curriculum

## Overview
Permanently remove a Draft or Archived curriculum **and every subject in it**. This can't be undone. If you might need it later, [archive it](archive-a-curriculum.md) instead.

## Before you begin
- The curriculum is **Draft** or **Archived**. Active curricula can't be deleted.

## Steps
1. Select **Curricula and Subjects** in the sidebar.
2. Select **Delete** on the curriculum's row.
   → The **Delete this curriculum?** dialog shows how many subjects will also be deleted.
3. Type the curriculum's name exactly in **Enter curriculum name**.
4. Select **Delete curriculum** (or **Delete curriculum & subjects**).
   → You'll see "[name] was permanently deleted."

[Screenshot: The Delete this curriculum dialog]

## Troubleshooting
| Problem | What to do |
|---|---|
| The delete button stays unavailable | Type the name exactly as shown, including capital letters and spaces. |
| There's no **Delete** button | The curriculum is Active. Deactivate it first. |
