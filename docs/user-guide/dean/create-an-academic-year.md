# Create or edit an academic year

## Overview
Add an academic year to the calendar. Every academic year includes three terms: 1st semester, 2nd semester, and Summer. New years start as drafts.

## Before you begin
- You're logged in as a Dean.

## Steps
1. Select **Enrollment Management** in the sidebar, then the **Academic years & terms** tab.
2. Select **Create academic year**.
3. Enter the **Academic year** by its starting year, e.g. *2028* for 2028–2029.
4. Select **Create academic year**.
   → You'll see "Academic year [year] created as a draft." It appears under **All academic years**.

**To edit a draft year**, select **Edit** on its row, change the starting year, and select **Save changes**.

Next: [Activate an academic year](activate-an-academic-year.md).

## Troubleshooting
| Problem | What to do |
|---|---|
| "Enter a valid starting year, such as 2028." | Enter a four-digit year. |
| "Academic year [year] already exists." | That year is already on the calendar. |
| "Only a draft academic year can be edited." | Active and completed years can't be edited. |
