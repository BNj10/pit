# Set the faculty evaluation window

## Overview
Choose when faculty evaluations start for a semester. Students, Department Chairs, and you can submit evaluations once it opens. There is no end date: the window stays open until you close it.

## Before you begin
- You're logged in as a Dean.

## Steps
1. Select **Faculty Evaluation** in the sidebar.
   → The **Semester evaluation window** card is at the top.
2. Select **Create window** (or **Edit window** to change an existing one).
3. Choose the **Academic year** and **Semester** (1st or 2nd).
4. Choose the day it **Starts on**. Choose today to start now, or a later day to schedule ahead.
5. Select **Create window** or **Save window**.
   → You'll see "Evaluation window created." (or "saved."). The badge shows **Open** or **Scheduled**.

While the window is open, the card shows completion for students, Department Chairs, and College Dean evaluations.

## Troubleshooting
| Problem | What to do |
|---|---|
| "Choose the day evaluations start." | Pick a start day. |
| "Select an available academic year and semester." | Choose from the years and semesters listed. |
| The badge says **Scheduled** | The start day is in the future. Evaluations open automatically on that day. |
