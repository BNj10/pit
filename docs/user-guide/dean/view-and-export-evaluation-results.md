# View and export a faculty member's evaluation results

## Overview
Review a faculty member's combined evaluation results for the term, including class ratings, insights, and comments, and save or print them as a report.

## Before you begin
- Evaluations have been submitted for the faculty member.

## Steps
1. Select **Faculty Evaluation**, then **View instructors**.
2. Select **View results** on the faculty member's row.
   → **Faculty Evaluation Results** opens, with:
   - **Evaluation ratings**: student evaluation results per class, with page buttons if there are many classes
   - **Rating insights**
   - **Qualitative comments and suggestions**
3. Select **Export PDF** to download the report.
   → You'll see "Faculty evaluation report exported."
4. Select **Print** to print it.

## Troubleshooting
| Problem | What to do |
|---|---|
| "Unable to export this report. Please try again." | Select **Export PDF** again. |
| The row shows **Evaluate** instead of **View results** | You haven't submitted your evaluation yet. [Evaluate the faculty member](evaluate-a-faculty-member.md). |
| You want an earlier term | See [View past evaluation results](view-past-evaluation-results.md). |
