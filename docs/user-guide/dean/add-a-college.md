# Add a college

## Overview
Create a college so its departments can be organized under it.

## Before you begin
- You're logged in as a Dean.
- Know the college's official name and a unique code. Optional: its official logo (PNG, JPG, or WebP, up to 2 MB).

## Steps
1. Select **Colleges & Departments** in the sidebar.
2. Select **Add college**.
3. Fill in the required fields (marked with *):
   - **College name**: the official name
   - **College code**: a unique code
4. Choose a system icon, or select **Upload official logo** to use the college's logo.
5. Optional: add a **Description**.
6. Select **Create college**.
   → The new college appears in the **Colleges** directory.

Next, add its departments: [Add or edit a department](add-or-edit-a-department.md).

## Troubleshooting
| Problem | What to do |
|---|---|
| "Enter the official college name." / "Enter a college code." | Fill in the required field. |
| "This college code is already in use. Enter a unique code." | Choose a different code. |
| "Choose a non-empty image no larger than 2 MB." | Use a PNG, JPG, or WebP logo of 2 MB or less. |
| "Discard this college draft? Your changes will be lost." | You closed the dialog with unsaved changes. Confirm to discard, or go back to keep editing. |
| "Could not create the college. Please try again." | Select **Create college** again. |
