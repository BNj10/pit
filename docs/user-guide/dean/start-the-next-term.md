# Start the next term

## Overview
Move the active academic year to its next term: 1st semester, then 2nd semester, then Summer. The term that was current is marked completed.

## Before you begin
- An academic year is active ([Activate an academic year](activate-an-academic-year.md)).

## Steps
1. Select **Enrollment Management**, then **Academic years & terms**.
2. Under **Active academic year**, select **Start term** next to the next term.
   → The dialog explains that this term becomes current and any current term is marked completed.
3. Select **Start term**.
   → You'll see "[term] of [year] started."

[Screenshot: The Active academic year card with Start term]

## Troubleshooting
| Problem | What to do |
|---|---|
| "Every term of [year] has started." | All three terms have started. When Summer is done, [complete the year](complete-an-academic-year.md). |
| "Terms can be started only in the active academic year." | Activate the year first. |
