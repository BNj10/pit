# Set the enrollment schedule

## Overview
Set when each year level can enroll. The schedule applies to every department, and enrollment opens and closes automatically at the times you set.

## Before you begin
- An academic year is active and has a current term.

## Steps
1. Select **Enrollment Management** in the sidebar, then the **Enrollment schedule** tab.
2. Under **Enrollment windows**, set **Opens on** and **Closes on** (date and time) for each **Eligible group**:
   - 4th year, 3rd year, 2nd year, 1st year, and Open enrollment.
   Leave a group blank to publish it later.
3. Select **Save draft** to keep your changes without publishing.
   → You'll see "Draft saved." Draft changes are not visible to students.
4. Select **Publish schedule**.
   → You'll see "Enrollment schedule published for [term]." If you left groups blank: "Published [n] of [total] groups… The others stay hidden from their students."

Each group's **Status** then shows Scheduled, Open, Closed, or Paused.

## Troubleshooting
| Problem | What to do |
|---|---|
| "No active academic year" | [Activate an academic year](activate-an-academic-year.md) first. |
| "[group]: set both the opening and closing date and time, or clear them to publish this group later." | Fill in all four values for that group, or clear them. |
| "[group]: the closing time must be after the opening time." | Fix the dates or times. |
| "Set at least one group's opening and closing times to publish." | Set at least one group. |
| "Unpublished changes" | You've changed the schedule since publishing. Publish again so students see it. |
| You need to stop enrollment now | [Pause enrollment](pause-or-resume-enrollment.md). |
