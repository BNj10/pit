# Add or edit a department

## Overview
Create a department under a college, or update an existing department's details.

## Before you begin
- The college exists ([Add a college](add-a-college.md)).

## Steps
1. Select **Colleges & Departments** in the sidebar.
2. On the college's card, select **Manage departments**.
   → The college's **Departments** list opens.
3. Select **Create department**, or select **Edit** on a department's row.
4. Fill in the required fields (marked with *):
   - **College**: the college this department belongs to
   - **Department name**: the official name
   - **Department code**: a unique code
5. Choose a system icon or upload the official logo. Optional: add a **Description**.
6. Select **Create department** or **Save changes**.
   → The department appears in the college's department directory.

## Troubleshooting
| Problem | What to do |
|---|---|
| "Select a college for this department." | Choose a college. If none are listed ("No colleges available"), add a college first. |
| "Enter the official department name." / "Enter a department code." | Fill in the required field. |
| "This department code is already in use. Enter a unique code." | Choose a different code. |
| "Choose a department icon or logo." | Pick a system icon or upload a logo. |
| "Choose a non-empty image no larger than 2 MB." | Use a PNG, JPG, or WebP logo of 2 MB or less. |
| "Discard this department draft? Your changes will be lost." | You closed the dialog with unsaved changes. Confirm to discard, or go back to keep editing. |
| "Could not create the department…" or "Could not update the department…" | Try again. |
