# Archive or restore past evaluation results

## Overview
Hide a completed term's results from the **Previous semester results** list to keep it tidy. Archived results keep all their data and can be restored at any time.

## Before you begin
- The term's evaluations have been closed.

## Steps
1. Select **Faculty Evaluation** and scroll to **Previous semester results**.
2. Select the archive button on the term's row.
   → The **Archive results for [term]?** dialog opens.
3. Confirm. To cancel, select **Keep in list**.
   → You'll see "Results for [term] archived."

**To restore:**
1. Select **Show archived ([n])** above the list.
2. Select the restore button on the term's row.
   → You'll see "Results for [term] restored."

## Troubleshooting
| Problem | What to do |
|---|---|
| **Show archived** isn't visible | No results are archived. |
| A term you closed again reappears | Closing a term again restores it to the list automatically. |
