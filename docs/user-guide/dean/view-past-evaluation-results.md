# View past evaluation results

## Overview
Look up evaluation results from completed terms. Past results are read-only.

## Before you begin
- At least one evaluation term has been closed.

## Steps
1. Select **Faculty Evaluation** in the sidebar.
2. Scroll to **Previous semester results**. Filter by **Academic year** if needed.
   → Each completed term shows faculty count, responses, and Student SET, Dept. Chair SEF, and Dean SEF averages.
3. Select the button to view results for a term.
   → The term's instructor results open.
4. Select an instructor's results button to see their evaluation summary.

[Screenshot: The Previous semester results table]

## Troubleshooting
| Problem | What to do |
|---|---|
| "No completed evaluation results are available for this academic year." | Choose another academic year. |
| "All completed results are archived. Choose Show archived to see them." | Select **Show archived** ([Archive or restore past results](archive-past-results.md)). |
| "Term results unavailable" | That term no longer exists. Go back to **Previous semester results**. |
