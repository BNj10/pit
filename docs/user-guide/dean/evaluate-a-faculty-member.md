# Evaluate a faculty member

## Overview
Complete the Dean's Evaluation of Faculty for each faculty member in your college during the evaluation period.

## Before you begin
- The evaluation window is open ([Set the faculty evaluation window](set-the-evaluation-window.md)).

## Steps
1. Select **Faculty Evaluation** in the sidebar, then **View instructors**.
2. Narrow the list with the department filter or **Search faculty…** (name, department, or rank).
3. Select **Evaluate** on the faculty member's row.
   → The **Dean's Evaluation of Faculty** form opens.
4. For each benchmark statement, choose a rating: **Always**, **Often**, **Sometimes**, **Seldom**, or **Never**. Use the suggested means for verification as your evidence.
5. Optional: add **Recommendations and Suggestions**.
6. Submit the evaluation.
   → You'll see "Evaluation submitted for [faculty member]." Their row now offers **View results**.

Each faculty member is rated once per term. Submitted evaluations are locked.

## Troubleshooting
| Problem | What to do |
|---|---|
| "No evaluation window has been created yet…" | [Create the evaluation window](set-the-evaluation-window.md) first. |
| "Evaluations will be available when the window opens." | The window is scheduled for a later day. |
| "This evaluation window is closed…" | Edit the window to accept ratings again. |
| "Select a rating for every statement." | Rate every statement before submitting. |
| "No instructors found" | Select **Clear filters**. |
