# PIT Enrollment System

Next.js application with Supabase CLI for local development.

## Prerequisites

- Node.js 20.9 or newer with npm.
- Docker Desktop running with Linux containers.

The Supabase CLI is pinned as a project development dependency. A global Supabase CLI installation, Supabase account, and hosted Supabase project are not required for local development.

## Local Development

Run the following commands from the project root:

```sh
npm install
npm run supabase:start
```

The first start downloads the required Docker images and may take several minutes.

The committed `supabase/config.toml` is already initialized for this project.

This project uses ports `55320-55329` and port `8084` for the Edge Functions inspector to avoid conflicts with another local Supabase project using the default ports.

Optional log analytics is disabled to reduce Docker memory usage.

### Environment Variables

Copy `.env.example` to `.env.local`.

PowerShell:

```powershell
Copy-Item .env.example .env.local
```

Then check the local Supabase services and credentials:

```sh
npm run supabase:status
```

Copy the **Publishable** key into:

```env
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=
```

The Supabase URL is already configured to use the local API.

Restart the Next.js development server after changing environment variables.

These environment variables are prepared for future Supabase client integration. The local Supabase CLI setup itself does not automatically connect the application's login UI.

### Start the Application

```sh
npm run dev
```

| Service | Local address |
| --- | --- |
| Application | http://localhost:3000 |
| Supabase API | http://127.0.0.1:55321 |
| Supabase Studio | http://127.0.0.1:55323 |
| Test email inbox | http://127.0.0.1:55324 |
| PostgreSQL | `postgresql://postgres:postgres@127.0.0.1:55322/postgres` |

Authentication redirects accept the local application on port `3000` using either `localhost` or `127.0.0.1`.

Email confirmation is disabled by default for local development. Email generated by the local Supabase stack can be inspected using the local test email inbox.
